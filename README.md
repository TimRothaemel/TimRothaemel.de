# Personal Portfolio Website

This repository contains the source code for my personal developer portfolio.

The goal of this website is to showcase my projects, technical skills, and development progress as a web developer.

Live Website:  
https://timrothaemel.netlify.app/

---

# Features

- **Bilingual interface** (German / English)
- **Responsive design** for desktop and mobile
- **Dark mode support**
- **GitHub contribution graph integration**
- **Dynamic skills section (loaded from JSON)**
- **Projects overview (loaded from JSON)** 
- **Downloadable CV**
- **Contact options (GitHub, Email, Instagram, LinkedIn)**

---

# Tech Stack

**Frontend**
- HTML5
- CSS3
- JavaScript (Vanilla)

**Tools & Integrations**
- GitHub Calendar API
- JSON for dynamic data loading
- Responsive layout with Flexbox / Grid
- marked.min.js for importing README.md Files from my repositories
